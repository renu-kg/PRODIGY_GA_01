# 🤖 Text Generation with GPT-2  

This project was created as part of my **Generative AI Internship at Prodigy InfoTech**.  
Here, I explored the fascinating world of **transformer-based language models** — using **OpenAI’s GPT-2** to generate coherent and contextually relevant text from custom prompts.  

---

## 📋 Overview  

The goal of this task was to **train and fine-tune GPT-2** on a chosen dataset to produce text that mimics the tone, style, and structure of the training data.  
By adjusting parameters like temperature and top-k sampling, the model learns to balance **creativity vs coherence** when generating text.  

---

## ⚙️ What This Project Does  

1. Loads a pre-trained **GPT-2 model** (from Hugging Face Transformers)  
2. Optionally fine-tunes it on a **custom dataset**  
3. Accepts a **prompt** from the user  
4. Generates **unique, human-like text continuations**
